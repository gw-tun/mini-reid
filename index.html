07 / Requirements

MVP acceptance checklist

Functional

  • RTSP paths load from MediaMTX
  • Record Search returns ranked evidence
  • Live Follow emits branch events
  • Person/vehicle pipelines stay separate

Performance

  • CPU-only startup works without CUDA
  • Queues are bounded and observable
  • ReID refresh is track-level
  • Approximate search is benchmarked against exact

Traceability

  • Model/version stored with vectors
  • Camera/time/crop stored with matches
  • Threshold policy is configurable
  • Operator review state is auditable
